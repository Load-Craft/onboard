# Recipe: mistakes to check before the commit

Use it in step 17. Read `git diff`. For every row: if your diff has the left side, change it to the right side.

| #   | Wrong                                                                                                                                   | Right                                                                                                                                                       |
| --- | --------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `name: flow.name` (a text field assigned as it is)                                                                                      | `name: thirdParty(ctx, flow.name, LIMITS.name)`                                                                                                             |
| 2   | `inline(entry.text, 300)`                                                                                                               | `thirdParty(ctx, entry.text, LIMITS.sentence)`                                                                                                              |
| 3   | a change in `src/security/`, or "this name is not a secret"                                                                             | STOP `S-07`                                                                                                                                                 |
| 4   | `item.created_at` printed as it is or passed as it is into a slot (`t(key, { at: item.created_at })`); `.slice(0, 10)`; `new Date(...)` | `t(key, { at: day(item.created_at) })` or `minute(item.created_at)`                                                                                         |
| 5   | a view line with the UUID of a run                                                                                                      | the handle: `data.run` (`e-1a2b3c4d`)                                                                                                                       |
| 6   | a hint that says "run process_get_status"                                                                                               | the hint key of `docs/recipe/texts.md` section 4: it names the tool that lists                                                                              |
| 7   | `lines.push('No versions yet')`; `lines.push(answer.message)`                                                                           | `lines.push(t('<tool_name>.empty'))`; a text of the backend goes through its mask row first, then into a slot: `t('<tool_name>.line', { text: item.text })` |
| 8   | `new ToolError('x', { message: '...' })`; `new ToolError('invalid', ...)`                                                               | `refuseRule('<key>')` with the key of `docs/recipe/texts.md` section 3                                                                                      |
| 9   | a rule checked after a read                                                                                                             | the rule is the first lines of `run`                                                                                                                        |
| 10  | `Promise.all([a, b])`                                                                                                                   | `settleAll([a, b])`                                                                                                                                         |
| 11  | `1. checkout, inactive` (a bare name)                                                                                                   | `1. "checkout" [id]` with `quoted()` and `idTag()`                                                                                                          |
| 12  | a key in `<module>.en.ts` that is not in `<module>.pl.ts`                                                                               | both files have the same keys                                                                                                                               |
| 13  | no sentence about the tool in the skill file                                                                                            | step 14                                                                                                                                                     |
| 14  | `git commit --amend` on a commit reported as merged                                                                                     | a new commit on a new branch: `git switch -c <branch>-2 <integration branch>`                                                                               |
| 15  | a rebase with no build after it                                                                                                         | `npm run build`, `npm run check:dist`, commit `dist/`                                                                                                       |
| 16  | "passed" read from the last lines of the output                                                                                         | `echo "exit $?"`; the count of test files is above zero                                                                                                     |
| 17  | `eslint-disable`, `@ts-ignore`, `as any`, a skipped test                                                                                | fix the cause, or STOP `S-14`                                                                                                                               |
| 18  | `git add -A`, `git add .`, `git stash`, `git push`                                                                                      | `git add <file> <file>`; nothing else                                                                                                                       |
